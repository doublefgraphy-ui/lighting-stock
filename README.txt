DUOMO 재고 확인 홈페이지

1. 바로 확인하기
- duomo-stock-site 폴더의 index.html을 더블클릭하면 PC에서 사용할 수 있습니다.
- 검색, 브랜드/유형/재고 필터, 상품 상세보기가 작동합니다.

2. 휴대폰과 매장에서 사용하기
- 폴더 안의 모든 파일을 GitHub Pages 또는 웹호스팅에 그대로 업로드합니다.
- 첫 접속 후 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
- 서비스워커가 적용되어 한 번 불러온 화면과 이미지는 오프라인에서도 다시 열 수 있습니다.

3. 데이터 기준
- 원본 파일: DUOMO_조명재고리스트 (신규)(1).xlsx
- 생성일: 2026-07-27
- 상품 항목: 355개
- 원본 엑셀의 INFO 시트는 상품 목록에서 제외했습니다.

4. 중요
- 현재 버전은 엑셀 내용을 정적 데이터로 변환한 스냅샷입니다.
- 엑셀 재고가 바뀌어도 웹사이트가 자동 갱신되지는 않습니다.
- 실시간 자동 갱신이 필요하면 Google Sheets 또는 별도 관리자 업로드 방식으로 연결해야 합니다.
